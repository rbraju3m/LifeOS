# ADR 0004: MySQL 8.4 LTS (InnoDB, utf8mb4)

- Status: Accepted (2026-11-18)
- Blueprint: [§10](../blueprint/10-database-schema.md)

## Decision
Use MySQL 8.4 LTS with InnoDB and `utf8mb4_0900_ai_ci`. The design relies on these features:
- `FOR UPDATE SKIP LOCKED` for the reminder dispatcher.
- Generated columns, to stand in for partial unique indexes.
- CHECK constraints.
- JSON columns.
- FULLTEXT indexes.

## Alternatives
**PostgreSQL:** has better JSON support, partial indexes and row-level security.

## Consequences
- There is no row-level security, so authorization is enforced in application policies and query scopes.
- Tests must run on MySQL, not SQLite.

## Migration risk
Medium if we move to Postgres later. To reduce it, keep MySQL-specific SQL inside repositories and migrations.
